# Novo Mundo: Basilis

RPG tático original com exploração, recrutamento, classes e construção de comunidade.

**Status:** protótipo 0.1 em desenvolvimento; ainda não validado em navegador.

## Executar

```bash
npm install
npm run dev
```

## Testes

```bash
npm test
npm run build
```

## Objetivo do protótipo
Criar um personagem, iniciar um pequeno combate tático, selecionar unidades, movimentar, escolher técnicas e encerrar turnos.

**Franquia:** Novo Mundo · **Jogo:** Basilis · **Stack:** Phaser 3, TypeScript, Vite e Vitest.

O motor é original. O jogo não utiliza ROMs comerciais.
